01

Neural Electrode Fabricator

Arduino MegaLaserMotion ControlPythonData LoggingMicroscopyNeurotech

A precision laser rig for preparing neural microelectrodes, with built-in data collection for testing how different motions affect the wire.

Neural interfaces depend on extremely fine conductive filaments — multiple material types, each under 20 µm in diameter. This rig holds a filament on a motorized linear stage and processes it with a PWM-controlled laser. It can cut the tip to a very sharp point and strip the insulation to a set length without damaging the conductor underneath.

Every run is logged automatically to CSV, and the firmware is built so that any motion profile — speed in mm/s, power as a percentage, single or dual pass — takes only a short command to run. That makes it quick to test a motion and see exactly how it affects the wire.

Key components
  • Arduino Mega controller
  • NEMA 17 stepper on a precision linear stage
  • 450 nm PWM-controlled diode laser module
  • Custom firmware for easy motion and power testing
  • Python serial logger for automatic CSV data collection
  • Microscope for imaging and inspection
02

Industrial Robotic Arm In Progress

ESP32-S3NEMA 17TMC2209Planetary GearboxPlatformIOLLM Control

A six-axis stepper-driven arm you can command in plain English.

A natural-language instruction is converted to structured JSON by a language model on a small backend server, then handed to an ESP32-S3 that generates the real-time step pulses for six motors. Each joint is driven through a custom planetary reduction to gain the torque and resolution the direct-drive prototype below couldn't offer. Currently in the wiring, firmware, and gearbox-build phase.

Key components
  • ESP32-S3 real-time motion controller
  • 6× NEMA 17 steppers with 6× TMC2209 drivers
  • Custom perfboard driver layout, 12 V motor supply
  • 3-stage 64:1 planetary gearbox, 3D printed
  • Language model → JSON → motion pipeline (Python backend)
  • PlatformIO firmware
03

Teleoperated Robotic Manipulator

PythonMediaPipeArduinoMG996RSolidWorks3D Print

A 4-DOF robotic arm that mirrors live hand motion in real time — from camera to servo, in one integrated pipeline.

MediaPipe extracts hand landmarks via Python, which serializes joint angles to an Arduino controlling MG996R servos. Structural components are custom-designed in SolidWorks and 3D printed. Key engineering challenges: insufficient holding torque and mechanical wobble under load, resolved by shortening arm length to reduce joint moment and redesigning link geometry for rigidity.

  • 4-DOF arm designed around MG996R servo actuation
  • Python + MediaPipe pipeline → serial → live servo control
  • Iterated 3D printed components to eliminate oscillation and instability
