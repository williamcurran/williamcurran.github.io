01

Neural Electrode Fabricator

Arduino MegaLaserMotion ControlPythonData LoggingMicroscopy

A precision laser rig for processing microelectrode wire, with built-in data collection for testing how different motions affect the wire.

The rig works with extremely fine wires — multiple material types, each under 20 µm in diameter — of the kind used to build neural microelectrodes. A wire is held on a motorized linear stage and processed with a PWM-controlled laser. It can cut the tip to a very sharp point and strip the insulation to a set length without damaging the conductor underneath.

All testing is done on the wires themselves. Every run is logged automatically to CSV, and any motion profile — speed in mm/s, power as a percentage, single or dual pass — takes only a short command to run, so it is quick to test a motion and see how it affects the wire.

Key components
  • Arduino Mega controller
  • NEMA 17 stepper on a precision linear stage
  • 450 nm PWM-controlled diode laser module
  • Custom firmware for easy motion and power testing
  • Python serial logger for automatic CSV data collection
  • Microscope for wire imaging and inspection
02

Industrial Robotic Arm In Progress

ESP32-S3NEMA 17TMC2209Planetary GearboxPlatformIOMotion Control

A six-axis stepper-driven arm built for brute strength and repeatable motion.

Six NEMA 17 steppers, each driven through a custom 64:1 three-stage planetary gearbox, give every joint high torque and fine positional resolution — the strength the direct-drive prototype below couldn't offer. Stepper-based motion returns to the same positions run after run, and an ESP32-S3 generates the step pulses for all six axes in real time. The mechanical and electrical builds are complete; the software is what I'm developing now.

Key components
  • ESP32-S3 real-time motion controller
  • 6× NEMA 17 steppers with 6× TMC2209 drivers
  • 3-stage 64:1 planetary gearbox, 3D printed
  • Custom perfboard driver layout, 12 V motor supply
  • PlatformIO firmware (in development)
03

Teleoperated Robotic Manipulator

PythonMediaPipeArduinoMG996RSolidWorks3D Print

A 4-DOF robotic arm that mirrors live hand motion in real time — from camera to servo, in one integrated pipeline.

MediaPipe extracts hand landmarks via Python, which serializes joint angles to an Arduino controlling MG996R servos. Structural components are custom-designed in SolidWorks and 3D printed. Key engineering challenges: insufficient holding torque and mechanical wobble under load, resolved by shortening arm length to reduce joint moment and redesigning link geometry for rigidity.

  • 4-DOF arm designed around MG996R servo actuation
  • Python + MediaPipe pipeline → serial → live servo control
  • Iterated 3D printed components to eliminate oscillation and instability
